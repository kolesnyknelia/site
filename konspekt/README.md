## Доступ лише за посиланням
- Конспект лежить у секретній папці: `https://konspektsayt.kvn.kiev.ua/<KONSPEKT_KEY>/`.
  Секрет `KONSPEKT_KEY` — у GitHub → Settings → Secrets and variables → Actions (латиниця, цифри, `-`, `_`).
- Корінь піддомену показує «Сторінку не знайдено»; `robots.txt`, `X-Robots-Tag` і `<meta name="robots">` забороняють індексацію.
- Посилання «злилося»? Змініть `KONSPEKT_KEY` і запустіть Actions → Deploy konspekt → Run workflow. Нове посилання вставте в SendPulse.
- `root/` — файли кореня піддомену (заглушка, robots.txt, .htaccess).

## Вхід за кодом з пошти (`gate/`)
- Учень вводить пошту → отримує 6-значний код → відкривається конспект. Вхід пам'ятається 30 днів.
- Ліміт пристроїв (за замовчуванням 2). Зайвий пристрій → доступ блокується на всіх пристроях + повідомлення в Telegram.
- Кабінет: `https://konspektsayt.kvn.kiev.ua/<KONSPEKT_KEY>/admin.php` — пароль із секрету `KONSPEKT_ADMIN_PASS`.
  Там: додати пошти учнів, розблокувати / скинути пристрої, увімкнути-вимкнути захист, Telegram для сповіщень, тестовий лист.
- Автододавання покупців: SendPulse → Automation 360 → дія «Відправити вебхук» на `hook.php?key=…&email={{email}}` (посилання з ключем — у кабінеті).
- Поки захист вимкнено в кабінеті — конспект відкривається за посиланням, як раніше.
- Сам конспект, скріни й архів скіла лежать у `private/` як `*.php` з `<?php exit; ?>` на початку — напряму не відкриваються,
  лише через `index.php` після входу. Дані учнів — `private/data/db.php` (створюється на хостингу, у git їх немає).

## Публікація
Після змін у `konspekt/` в гілці `main` сайт сам заливається в `/kvn.kiev.ua/konspektsayt/`
(`.github/workflows/deploy-konspekt.yml`). Один раз: у adm.tools має бути піддомен `konspektsayt`
з увімкненим SSL. Якщо папка піддомену називається інакше — змініть `DEPLOY_DIR` у workflow
(подивитися структуру: Actions → Inspect hosting folders).
