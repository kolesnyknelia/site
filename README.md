# Сайт за 1 вечір з ШІ: лендінг для продажу навчання

Односторінковий сайт, що продає курс зі створення лендінгів за допомогою штучного інтелекту.
Українською, mobile-first, інтерактивний (звуки кнопок, калькулятор, живі приклади, генератор промпту, конфеті), з функцією «Поділитися».

## Структура
```
index.html            головний продаючий лендінг
css/style.css         стилі
js/config.js          ⚙️ НАЛАШТУВАННЯ: Instagram, ціни, оплата, відгуки, Pixel
js/main.js            логіка (звуки, форма, калькулятор, поширення)
examples/             4 приклади сайтів: товарка, експерт, тренер, психолог
backend/              прийом заявок → Google Таблиця + Telegram
docs/                 оферта і політика конфіденційності (шаблони)
DEPLOY.md             публікація: GitHub Pages + домен
STRATEGY.md           воронка, тарифи, розрахунок прибутку, таргетинг, креативи
```

## Швидкий старт
1. Відредагуйте `js/config.js`.
2. Підключіть заявки за інструкцією `backend/README.md`.
3. Опублікуйте через GitHub Pages + свій домен: `DEPLOY.md`.
4. Пройдіть чек-лист у `STRATEGY.md`.

Локальний перегляд: `python3 -m http.server 8000` → http://localhost:8000
