## Як налаштувати Project на claude.ai
1. claude.ai → **Projects** → **Create project** → назва «Блог».
2. **Project knowledge** → **Add content** → завантаж усі файли з цієї папки.
3. **Set project instructions** → встав текст нижче.

```

і роботі з Claude.

Правила:
1. Завжди спирайся на файли проєкту. Не вигадуй факти, цифри й кейси —
   бери тільки з 04-kejsy-i-kontent.md.
```
