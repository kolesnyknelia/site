# 🤖 Бот «Недозвон» для LP-CRM

Бот пише клієнтам, до яких не додзвонились, отримує від них дані доставки, сам створює ТТН у Новій пошті й ставить замовленню в LP-CRM статус «Принят».

## Як це працює

1. **Щохвилини** `cron.php` питає в LP-CRM замовлення зі статусом **«Недозвон»** (список статусів задається в `settings.php` → `watch`).
2. Через 2 хвилини клієнт **один раз** отримує повідомлення у **Viber з фото товару й кнопкою**. Якщо Viber не дійшов, надсилається **SMS** (через TurboSMS). Повідомлення йдуть лише з 9:00 до 21:00.
3. Кнопка й посилання ведуть на сторінку `go.php`, де клієнт обирає **Telegram** або **Viber**. Бот одразу показує його замовлення: товар, суму і кнопки «Підтверджую», «Змінити», «Скасувати».
4. Бот запитує й перевіряє:
   - **прізвище та ім'я** (пропонує ті, що є в CRM);
   - **номер телефону** (показує номер з CRM, клієнт підтверджує або пише інший);
   - **місто** (пошук у Новій пошті, вибір кнопкою);
   - **відділення чи поштомат** (за номером, вибір кнопкою).
5. Після кнопки «Все вірно, оформити»:
   - **ТТН створюється в Новій пошті** (з накладеним платежем на суму замовлення);
   - у **LP-CRM** ставиться статус **«Принят»**, записуються ТТН, ПІБ, телефон, адреса, а в коментар додається «🤖 Прийняв бот (Telegram) 02.11 15:20, ТТН …»;
   - клієнт отримує номер ТТН і посилання на відстеження;
   - у Telegram-групу операторів приходить звіт.
6. Якщо оператор **уже обробив** замовлення (статус змінено), бот **не створює** другу ТТН і лише попереджає операторів.
7. Питання клієнтів («а коли приїде?», «хочу інший розмір») бот пересилає в групу операторів. Оператор натискає **«Відповісти»** на повідомлення бота, і відповідь іде клієнту в Telegram чи Viber.

## Що потрібно один раз

| Що | Де взяти | GitHub Secret |
|---|---|---|
| Telegram-бот | @BotFather → `/newbot` → токен | `NZ_TG_TOKEN` |
| Група операторів | Створіть групу, додайте бота, напишіть у групу, ID групи (з мінусом) покаже @RawDataBot | `NZ_TG_OPS_CHAT` |
| TurboSMS | turbosms.ua → API → токен | `NZ_TURBOSMS_TOKEN` |
| Альфа-ім'я SMS | TurboSMS → «Відправники» (реєстрація кілька днів) | `NZ_SMS_SENDER` |
| Альфа-ім'я Viber | TurboSMS → Viber-відправник | `NZ_VIBER_SENDER` (необов'язково) |
| Нова пошта | Особистий кабінет НП → Налаштування → Безпека → API-ключ | `NZ_NP_KEY` |
| Секрет | Будь-які 30+ випадкових літер і цифр | `NZ_SECRET` |
| Viber-бот | partners.viber.com (платний), токен і URI | `NZ_VIBER_TOKEN`, `NZ_VIBER_URI` (необов'язково) |

LP-CRM: ключ і домен воркфлоу бере сам з будь-якого вашого сайту, де LP-CRM уже працює (поле `lpcrm_source`). Їх також можна задати секретами `NZ_LPCRM_DOMAIN` і `NZ_LPCRM_KEY`.

Секрети додаються так: GitHub → **Settings → Secrets and variables → Actions → New repository secret**.

## Запуск

1. Перевірте `nedozvon/settings.php`:
   - назви статусів, як у вашій LP-CRM (`Недозвон`, `Принят`, `Відмова`);
   - місто й номер відділення, з якого відправляєте;
   - вагу й габарити посилки;
   - вид накладеного платежу.
2. Після злиття в `main` файли автоматично потрапляють на хостинг (`kvn.kiev.ua/nedozvon/`).
3. Запустіть **Actions → Nedozvon bot setup → Run workflow** (у полі `lpcrm_source` вкажіть файл з робочим LP-CRM). У кінці лога буде перевірка: усі рядки мають бути з ✅.
4. **Cron на хостингу** (adm.tools → Хостинг → Планувальник завдань / Cron): щохвилини запускати PHP-скрипт
   `kvn.kiev.ua/www/nedozvon/cron.php`
5. Тест: поставте якомусь тестовому замовленню (зі своїм номером) статус «Недозвон» і зачекайте 2–3 хвилини.

Пробний запуск без відправки SMS: `php cron.php --dry`

## ⚠️ Що треба перевірити на першому реальному замовленні

- **Оновлення замовлення в LP-CRM.** Бот викликає метод `updateOrder` (назва задається в `settings.php` → `lpcrm_update_method`). Якщо LP-CRM відповідає помилкою, бот пише операторам «⚠️ LP-CRM не оновилась — поставте статус і ТТН вручну», а ТТН при цьому вже створена. Тоді назву методу треба звірити з документацією API у вашій LP-CRM.
- **Накладений платіж.** `backward` означає звичайний «Грошовий переказ». Якщо у вас ФОП з «Контролем оплати», поставте `afterpayment`.

Журнал роботи: `/kvn.kiev.ua/private/nedozvon/log-РРРР-ММ.txt`

Автотест (імітації LP-CRM, НП, Telegram, Viber і TurboSMS): `python3 backend/tests/test_nedozvon.py`
