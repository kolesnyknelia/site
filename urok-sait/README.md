# Урок «Частина 3. Сайт під товар»

| Файл | Що це |
|---|---|
| `urok.html` | Текст уроку українською. Відкрийте в браузері → кнопка «Копіювати урок для SendPulse» → вставте в текстовий блок уроку |
| `prompt.txt` | Промпт для учнів (той самий, що в кроці 4 уроку) |
| `sait-pid-tovar.zip` | Скіл «Сайт під товар» — прикріпіть до уроку як файл. Учні перетягують його в Claude: «Встанови цей скіл» |
| `skill/sait-pid-tovar/` | Вихідні файли скіла (інструкція `SKILL.md` + готовий шаблон сайту `template/`) |

## Як перенести в SendPulse
1. Блок «Текст» → вставити скопійований урок.
2. На місці рожевих рамок «🖼 Скрін: …» — додати свої скріни (блок «Зображення»), рамки видалити.
3. Блок «Файл» у кроці 1 → `sait-pid-tovar.zip`.
4. Замінити приклади сайтів (`tovar.vash-domen.shop`, `nazva.vercel.app`) на свої живі приклади і вписати дедлайн.

## Як перезібрати архів скіла після змін
```bash
cd urok-sait/skill && rm -f ../sait-pid-tovar.zip && zip -rq -X ../sait-pid-tovar.zip sait-pid-tovar
```
