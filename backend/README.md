# Заявки з сайту → Google Таблиця + Telegram (безкоштовно, ~10 хвилин)

1. **Telegram-бот.** Напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → скопіюйте токен.
   Напишіть своєму боту будь-що. Дізнайтесь свій chat id у [@userinfobot](https://t.me/userinfobot).
2. **Google Таблиця.** Створіть нову таблицю → меню *Розширення → Apps Script*.
3. Вставте код з `google-apps-script.js`, впишіть `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`, збережіть.
4. *Розгорнути → Нове розгортання → Тип: Веб-застосунок*.
   Виконувати від імені: **Я**. Доступ: **Усі**. → *Розгорнути* → дозволити доступ.
5. Скопіюйте URL веб-застосунку (`https://script.google.com/macros/s/.../exec`)
   і вставте його в `js/config.js` → `formEndpoint`.
6. Перевірте: залиште тестову заявку на сайті — вона з'явиться в таблиці й прийде в Telegram.

> Якщо змінюєте код скрипта — робіть *Розгорнути → Керувати розгортаннями → Редагувати → Нова версія*, інакше зміни не застосуються.
