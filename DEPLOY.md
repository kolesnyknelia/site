# Публікація сайту на хостинг kvn.kiev.ua (автоматично через FTP)

Після кожної зміни в гілці `main` GitHub сам завантажує сайт на хостинг у папку `/kvn.kiev.ua/www/`
(файл `.github/workflows/deploy.yml`, дія SamKirkland/FTP-Deploy-Action).
Завантажуються лише змінені файли, тому оновлення займає ~1 хвилину.

## Крок 1. Додати FTP-доступи в GitHub (1 раз)
https://github.com/kolesnyknelia/site → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
Створіть три секрети (дані — у панелі хостингу, розділ FTP):

| Name | Значення |
|------|----------|
| `FTP_SERVER` | адреса FTP-сервера, напр. `ftp.vash-hosting.ua` (без `ftp://`) |
| `FTP_USERNAME` | логін FTP |
| `FTP_PASSWORD` | пароль FTP |

Секрети зашифровані: їх не видно ні в коді, ні в логах.

## Крок 2. Запустити
- Автоматично: будь-яка зміна в `main`.
- Вручну: вкладка **Actions** → **Deploy to hosting (FTP)** → **Run workflow**.

Зелена галочка ✅ у вкладці Actions = сайт оновлено. Червоний хрестик ❌ — відкрийте запуск і подивіться помилку
(найчастіше: неправильний сервер/логін/пароль або хостинг блокує FTP з-за кордону — тоді попросіть підтримку хостингу дозволити підключення).

## Що НЕ завантажується на сервер
`.github/`, `backend/`, `README.md`, `STRATEGY.md`, `DEPLOY.md` — це службові файли, на сайті вони не потрібні.

## Як оновлювати сайт
Змінюєте файл у GitHub (олівчик ✏️ → **Commit changes** у `main`) → через хвилину зміни на kvn.kiev.ua.
Найчастіше редагується лише `js/config.js` (ціни, посилання, відгуки).

## ⚠️ Про публічність
Репозиторій **публічний**: усі файли, включно зі `STRATEGY.md`, видно на GitHub.
FTP-пароль і токени Telegram у репозиторії **не зберігаються**.
