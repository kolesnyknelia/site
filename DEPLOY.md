# Публікація сайту: GitHub Pages + ваш домен

Після налаштування **кожна зміна в гілці `main` автоматично з'являється на сайті** через 1–2 хвилини. Хостинг безкоштовний, HTTPS теж.

## Крок 1. Увімкнути GitHub Pages (1 раз)
1. Відкрийте https://github.com/kolesnyknelia/site → **Settings** → **Pages**.
2. **Source:** `Deploy from a branch`.
3. **Branch:** `main`, папка `/ (root)` → **Save**.
4. Через 1–2 хв сайт буде доступний за адресою https://kolesnyknelia.github.io/site/

> Сайт публікується з гілки `main`. Зміни з робочої гілки потрапляють на сайт після злиття (merge) у `main`.

## Крок 2. Підключити свій домен
1. Там само, **Settings → Pages → Custom domain**: впишіть домен (напр. `vashdomen.com`) → **Save**.
   GitHub сам створить у репозиторії файл `CNAME`.
2. У кабінеті, де купували домен, у розділі **DNS** додайте записи:

| Тип | Ім'я (Host) | Значення |
|-----|-------------|----------|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `kolesnyknelia.github.io` |

   Старі A-записи для `@` (від хостингу реєстратора) видаліть.
3. Зачекайте від 15 хвилин до кількох годин, поки DNS оновиться.
4. Поверніться в **Settings → Pages** і поставте галочку **Enforce HTTPS**.

## Крок 3. Перевірка домену в Meta (для реклами)
Meta Business Manager → **Налаштування компанії → Безпека бренду → Домени** → додати домен → спосіб **DNS TXT** → додайте TXT-запис у DNS так само, як у кроці 2.

## Як оновлювати сайт
- Змінюєте файл у GitHub (олівчик ✏️ → **Commit changes** у `main`) → сайт оновлюється сам.
- Найчастіше редагується лише `js/config.js` (ціни, посилання, відгуки).

## ⚠️ Про публічність
Репозиторій **публічний**: усі файли, включно зі `STRATEGY.md`, видно в інтернеті.
Токени Telegram-бота **не зберігаються** в репозиторії: вони лише в Google Apps Script.
Якщо хочете приховати стратегію, перенесіть `STRATEGY.md` в окремий приватний репозиторій або Google Doc.
